# Regalia — Palatial Banquet Venue & Party Hall HTML Template

A luxury, editorial-style multipurpose HTML template for banquet halls, wedding venues, party halls, and celebration spaces. Inspired by the royal hospitality aesthetics of The Leela Palace Newport, RI and the practical booking journey of KM Palace.

### Key Highlights
- **Strict 3-Colour Palette**: Obsidian Black (`#171419`), Warm Ivory (`#F6F0E7`), Royal Plum (`#54264B`).
- **Strict 2-Font Typography**: Playfair Display & Inter.
- **Full Viewport Width Design**: Every major section spans 100% width with 30px horizontal padding on desktop/tablet (16-20px on mobile).
- **21 Complete Public Pages**: Including 2 homepages, hall filters, single hall audit, services, package comparisons, lightbox gallery, pricing guide, and editorial blog.
- **Interactive 9-Step Booking Wizard**: Live reactive calculations in INR (₹) with 25% advance estimate and localStorage persistence.
- **13-Page Client Dashboard**: For hosts to track bookings, request date changes, view catering selections, and download tax invoices.
- **16-Page Admin Dashboard**: For venue operations to approve/reject bookings, block dates on the master calendar, manage pricing, and export reports.
- **Dual Theme Support**: Light Mode (default) & Obsidian Dark Mode with automatic system preference detection.
- **Full RTL Support**: True document `dir="rtl"` layout mirroring for Arabic and Hebrew.
